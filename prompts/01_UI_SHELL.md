# FAZ 1 — Premium monochrome UI shell ve gezinme

`ui-ux-monochrome` skill ve `docs/06_UI_UX_DESIGN_SYSTEM.md` esas alınır.

## Hedef
Gerçek veri bağlanmadan profesyonel ve responsive temel paneli tamamla. Placeholder verilerin hepsi açıkça `DEMO` veya `sample` olarak işaretlenmeli; kullanıcı bunları gerçek piyasa verisi sanmamalı.

## Yapılacaklar
1. Sidebar nav: Overview, Products, Research, Price monitoring, Pricing analysis, Data sources, Settings.
2. Topbar: breadcrumb/title, global search placeholder, New research button, provider health, theme toggle.
3. Dashboard layout: KPI strip, price movement chart placeholder, recent research table, source status panel.
4. Light/dark theme tokens; localStorage theme preference (sadece UI preference).
5. Empty states, loading skeletons, error states reusable component.
6. Button, input, select, modal, tabs, badge, table, tooltip primitives.
7. 1440/1024/390 responsive layout.
8. Navigation routes and active menu states.
9. Keyboard/focus and semantic accessibility.
10. Screenshot tests / visual review notes.

## Sınırlar
- Gerçek KPI veya rastgele fiyat üretme.
- Ürün/araştırma CRUD yok; yalnızca shell and sample empty state.
- Çok renkli kart ve gereksiz gradient yok.
